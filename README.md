Sizzle & Serve — a fast top-down cooking game: run the kitchen, chop, grill, plate and serve orders before the shift ends. Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. WASD or arrows to walk, click to walk somewhere, E to use a station, hold E to chop, M to mute, P to pause.
